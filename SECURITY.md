# Security

This repository contains documentation and small client-side checks. Please do not open issues containing API keys, cookies, account credentials, private WHOIS data, or other secrets.

The examples are intended for domains you own, operate, evaluate, or are otherwise permitted to test. They perform ordinary DNS lookups and HTTP requests only.

Security reports concerning AIYucha itself should be sent through the contact channel published on https://aiyucha.com rather than posted with sensitive details in a public issue.
