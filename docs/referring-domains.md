# Referring domains

A referring domain is an independent domain that links to the target. It reduces some of the distortion created by repeated links from the same website.

Useful checks include:

- total referring domains versus total backlinks;
- top referring domains by link volume;
- distribution across TLDs and countries where relevant;
- topical relevance to the domain's historical use;
- whether the same small group accounts for most links;
- lost versus still-live referring domains.

A large referring-domain count is still not automatically “good.” Spam networks can contain many domains. The number becomes meaningful when paired with source quality, historical continuity, and context.

For expired or old domains, compare referring domains with archived site topics. A domain that once covered travel but later accumulated unrelated gambling anchors should be treated differently from a domain whose link neighborhood stayed coherent.
